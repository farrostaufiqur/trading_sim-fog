How this simulator works
Setup fields
Balance
Starting cash for every simulation. Each of the N simulations restarts from this same amount.
Buy %
How much of your current balance is staked when an epoch happens to be a buy (long) trade. E.g. balance 1,000 and Buy % 33 → that trade stakes 330.
Sell %
Same as Buy %, but for a sell (short) trade. Each epoch is randomly one or the other, never both — set Buy % and Sell % to the same number to simulate a single instrument with one bet size (no long/short distinction).
Spread %
The buy/ask vs sell/bid price gap — a cost taken out of the staked amount on every trade, win or lose. Set to 0 to ignore trading costs.
Profit % (weight)
How likely a trade is a win. Compared against Loss % to get the win chance — e.g. Profit % 50 and Loss % 50 means a 50/50 coin flip; Profit % 70 and Loss % 30 means a 70% win rate.
Loss % (weight)
The counterpart to Profit % — how likely a trade is a loss.
Profit amount / range
The payout on a winning trade, as a % of the staked amount. 100 means the stake doubles. Turn on the range toggle to pick a random value between a min and max instead of a fixed number.
Loss amount / range
The cost of a losing trade, as a % of the staked amount. 60 means you lose 60% of what was staked on that trade. Same min/max range toggle as profit.
Number of simulations
How many independent, separate accounts (N) to run — like N different people all using the same strategy. Each one starts fresh from the same Balance.
Max epoch
How many trades each simulation makes before stopping. Balance can go negative and trading keeps going regardless — a simulation only stops early if you hit Stop.
While running / finished (monitor view)
Simulation x / N
Which of the N independent simulations is currently in progress (or was the last one run).
Epoch x / max
How many trades into the current simulation you are.
Balance
The current simulation's live balance. Green when ≥ 0, red when negative.
Pool
The size of the most recent trade's stake, for visibility into how much was just risked. It's already folded into Balance the same epoch it happens — not separate money sitting on the side.
Best epoch / Worst epoch
The highest and lowest balance seen so far within the current simulation only (resets each time a new simulation starts).
Last trade
The direction (BUY/SELL) and outcome (PROFIT/LOSS) of the most recent trade.
Chart
The balance curve of the simulation currently in progress, one point per epoch. Bright green/red is the active streak (the run of trades leading to right now); dim green/red is older history within the same simulation. The dashed line is your starting balance; the red dashed line (when visible) is zero. The vertical scale focuses on where most points actually are (5th-95th percentile) so one extreme spike doesn't flatten everything else.
Ranking (after all N finish)
Every simulation's final balance, ranked best to worst: Most profitable (rank 1), Lowest still positive (the worst simulation that still ended ≥ 0), Middle (median), Least negative (the best simulation that still ended below 0), and Most negative (rank N, the worst outcome).
View rank
Once finished, enter any rank (1 to N) and click View to see that specific simulation's own epoch-by-epoch chart and final balance, instead of only the last one run. "Back to latest" returns to the default view.
Start / Stop / Reset
Start begins a run (or repeats the last config once finished). Stop ends the run early, keeping whatever simulations already completed. Reset clears everything and brings back the setup form.
